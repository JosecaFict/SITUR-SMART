Recomendaciones:
- Orientacion horizontal.
- Resolucion recomendada: 1920 x 1080 px.
- Para publicar en produccion se recomienda optimizar cada imagen despues de
  aprobar visualmente las versiones mejoradas.
- Evitar texto dentro de la fotografia.
- Mantener el punto de interes cerca del centro.

El carrusel cambia automaticamente cada 4 segundos. Si una imagen no existe,
el panel mantiene el degradado de respaldo.
