# Mockup: búsqueda pública del marketplace

Prototipo visual (estático) de la primera pantalla que verá cualquier
visitante sin login. Construido con la identidad visual real del proyecto
(`web/src/styles.css`: Poppins/Inter, verde-teal de marca, mismos radios
y estilos de botón que el login).

Publicado como Artifact: https://claude.ai/code/artifact/204ea6ea-ea3c-4ca2-9556-947222525194

`Main.dc.html` + `canvas.json` son el formato "Design Component" del
editor de canvas de Claude Design — no son código Angular, son
referencia de diseño para cuando se construya la página real.
